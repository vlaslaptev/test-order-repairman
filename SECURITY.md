# Security policy

## Supported versions

Security reports are welcome for the latest release available on
[JetBrains Marketplace](https://plugins.jetbrains.com/plugin/23151-test-order-repairman)
and for the current `main` branch. Fixes are intended for a future release of the
current codebase. Separate security backports for older releases are not promised.

Use the [README compatibility section](README.md#compatibility) for the declared
IDE and runtime range. A version submitted for Marketplace review is not
necessarily available to users yet.

## Report a vulnerability privately

Email **[vlaslaptev@gmail.com](mailto:vlaslaptev@gmail.com)** with the subject
**[Test Order Repairman] Security report**. This is the maintainer contact
published in the plugin metadata.

Please include:

- The affected plugin version and IntelliJ IDEA version/build.
- A description of the vulnerability, its potential impact, and any required
  conditions.
- Minimal reproduction steps or a synthetic proof of concept.
- Whether you are aware of public disclosure or exploitation.
- How you would like to be credited, if applicable.

Do not open a public issue or pull request containing vulnerability details before
coordinating disclosure. Do not send credentials, private project sources, or
unnecessary personal data. Email is the reporting channel; it is not a promise of
end-to-end encryption.

## What happens next

The maintainer will review the report, ask for clarification if needed, and
coordinate remediation and public disclosure with the reporter. This is a
volunteer-maintained project with no guaranteed response or fix timeline. If you
have not received a reply after seven days, please follow up in the same email
thread.

Ordinary bugs and feature requests belong in
[GitHub Issues](https://github.com/vlaslaptev/test-order-repairman/issues).
