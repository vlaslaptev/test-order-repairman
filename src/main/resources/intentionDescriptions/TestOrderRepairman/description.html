Renumbers JUnit Jupiter @Order values from 1 in the order test methods appear in the current Java class. Only already annotated test methods declared directly in that class are changed. Nested classes, extension fields, and helper methods are excluded.

Invoke with Alt+Enter inside a test method's @Order annotation. Annotation names and imports are preserved. Constant expressions are replaced with integer literals only when their values must change. The intention is unavailable if all values already match or an order value cannot be evaluated.

The intention does not configure JUnit's orderer. Use @TestMethodOrder(MethodOrderer.OrderAnnotation.class) to run tests by these values.
