Marketplace description

Renumber JUnit @Order values with Alt+Enter.

Added a test, moved a method, or ended up with duplicate numbers? Test Order Repairman assigns consecutive @Order values in the order your test methods appear in the Java source file.

From 3, 1, 2 to 1, 2, 3

  • Work on one class. Renumber already annotated test methods declared directly in the selected class, starting at 1.
  • Keep your code in place. Method locations, annotation names, and imports stay as they are.
  • Handle more than literals. Resolve integer constants, constant expressions, and negative values before making changes.
  • Keep other scopes intact. Neighboring classes, nested classes, extension fields, and helper methods are excluded.

How to use it

  1. Place the caret inside a test method's @Order annotation.
  2. Press Alt+Enter.
  3. Choose Renumber JUnit @Order values in this class.

Works with Java and JUnit Jupiter: regular, repeated, and parameterized tests, test factories, templates, and composed test annotations.

Running tests in this order

Configure @TestMethodOrder(MethodOrderer.OrderAnnotation.class) on your test class, or the equivalent JUnit default orderer. The intention updates annotation values; JUnit controls execution order.

Invoke the action when you need it. Values that already match their position keep their original expression. A changed expression becomes an integer literal; shared constant declarations are preserved. The action is unavailable when numbering already matches or a participating order value is invalid or unresolved. Methods without @Order are left unchanged.
