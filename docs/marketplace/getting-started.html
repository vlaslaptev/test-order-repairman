Renumber your first test class

  1. Install Test Order Repairman from Settings / Preferences > Plugins > Marketplace in a compatible IntelliJ-based IDE.
  2. Open a Java class with JUnit Jupiter test methods annotated with org.junit.jupiter.api.Order.
  3. Place the caret anywhere inside one of those @Order annotations.
  4. Press Alt+Enter and select Renumber JUnit @Order values in this class.

A complete example

import org.junit.jupiter.api.MethodOrderer;
import org.junit.jupiter.api.Order;
import org.junit.jupiter.api.Test;
import org.junit.jupiter.api.TestMethodOrder;

@TestMethodOrder(MethodOrderer.OrderAnnotation.class)
class ExampleTest {
    @Test @Order(3)
    void first() {}

    @Test @Order(1)
    void second() {}

    @Test @Order(2)
    void third() {}
}

After the intention, these methods have values 1, 2, and 3 in source order. The methods themselves are not moved.

What changes

Only existing @Order values on test methods declared directly in the selected class are renumbered. Invoke inside a nested class to process that class separately. Extension fields, class annotations, helper methods, inherited methods, and methods without @Order are excluded.

Resolved constants and constant expressions are supported. Expressions whose values must change become integer literals; their shared declarations are not edited. An expression that already equals its method's position is preserved.

If the action does not appear

  • Check that the file is writable Java source and uses JUnit Jupiter, not JUnit 4.
  • Place the caret inside a test method's @Order, rather than on a class, field, or helper method.
  • Wait for the IDE to finish indexing so annotation and constant references can resolve.
  • Check all participating @Order values in the class. Invalid, unresolved, incomplete, or duplicate annotations prevent the whole operation.
  • If the numbering already matches 1, 2, 3, … in source order, there is nothing to renumber.

The declared IDE range for the prepared update remains IntelliJ IDEA 2021.3.3–2023.2.x with Java support. Newer IDE compatibility is not claimed.
