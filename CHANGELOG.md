# Changelog

## 1.2 — 2026-10-16

- Limit renumbering to test methods declared directly in the selected class.
- Preserve annotation names, imports, and expressions that already match their position.
- Normalize duplicate, shifted, and permuted values in source order.
- Evaluate integer constants and expressions, including negative values, before editing.
- Skip the whole operation for invalid, unresolved, incomplete, or duplicate annotations.
- Support regular, repeated, parameterized, factory, template, and composed tests.
- Align the minimum IDE SDK and compiler target with Java 11.
- Add light and dark SVG logos with the selected @-and-arrow motif, a coordinated
  media gallery, and Marketplace copy.
- Document the Alt+Enter workflow and JUnit execution-order configuration.
